# 0build Context Index

This document indexes all context files for **0build** (Utilities, Runtime, and Kit components).

## Instructions for AI / LLMs

For better context, please download/fetch the relevant files below based on what you are building, or ask the user to manually upload them if you do not have web access:

1. **Always start with the essentials**:
   - `https://0build.dev/boilerplate.txt` — HTML boilerplate and CDN setup.
   - `https://0build.dev/contexts/utilities-introduction.md` — How 0build utilities work (CSS variables, `=` shorthand, states, breakpoints, dark mode).
   - `https://0build.dev/contexts/utilities-usage.md` — Concise, token-efficient reference of all utility classes.
2. **Fetch only the Kit components you need**:
   - Prefer **`kit-usage`** (`https://0build.dev/contexts/kit-usage/<component>.md`) first — these are concise, AI-optimized files designed to save tokens while preserving all classes, attributes, options, and JavaScript APIs.
   - Use **`kit-implementation`** (`https://0build.dev/contexts/kit-implementation/<component>.md`) only if you need extended human-oriented examples.
